Optional virtual-wrench reconciliation module

The standard path controller can be used without any research module. For fault-tolerant allocation experiments, enable the optional model-aided virtual-wrench module.

DAVE dependency: The module uses DAVE odometry and BlueROV2 direct thruster commands. Install and run DAVE ROS 2 BlueROV2 first: DAVE ROS 2 documentation.

Logic

The controller reconstructs an estimated achieved wrench from measured body velocity and a BlueROV2 hydrodynamic model:

tau_est = M_eff * nu_dot + D(nu) * nu

It compares this with the nominal wrench predicted by the allocation matrix:

e_a = tau_est - B*u - rhat_a

Then it updates a bounded virtual-wrench estimate:

rhat_a(k+1) = Proj_R( rhat_a(k) + gain * e_a )

The allocation target becomes:

tau_target = tau_command - rhat_a

Enable and reset

ros2 service call /path_controller/enable_reconciliation std_srvs/srv/SetBool "{data: true}"
ros2 service call /path_controller/reset_reconciliation std_srvs/srv/Trigger "{}"

TopicMeaning

Troubleshooting diagnostics

ros2 topic list | grep reconciliation
ros2 topic echo /path_controller/reconciliation/rhat
ros2 topic echo /path_controller/reconciliation/raw_residual
