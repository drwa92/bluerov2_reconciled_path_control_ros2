Service-driven BlueROV2 path following with optional virtual-wrench reconciliation.

A clean ROS 2 controller for DAVE/Gazebo that lets a BlueROV2 go to poses, follow waypoints, circles, spirals, and generic trajectories using direct six-thruster allocation. The optional research layer adds model-aided wrench reconstruction and projected virtual-wrench reconciliation.

DAVE simulator required: This package is designed for the ROS 2 DAVE BlueROV2 simulator. Install and verify DAVE before using the controller: DAVE ROS 2 BlueROV2 simulator documentation.

Features

Mission services

Call ROS 2 services for go-to, waypoint lists, circle, spiral, generic trajectory, stop, and emergency stop.

Direct thruster control

Publishes directly to DAVE BlueROV2 Gazebo thrust topics through ros_gz_bridge.

Rate-aware allocation

Maps virtual forces into six thruster commands while enforcing command magnitude and slew limits.

Research reconciliation

Optionally estimates a net virtual-wrench defect and compensates it through the allocation target.

Prerequisites

  • ROS 2 Jazzy or a compatible ROS 2 distribution.
  • DAVE ROS 2 BlueROV2 simulator: installation guide.
  • ros_gz_bridge for ROS-to-Gazebo thruster command bridging.
  • DAVE launched in direct-control mode with use_ardusub:=false and use_teleop:=false.

Quick command preview

# Launch DAVE first
ros2 launch dave_demos dave_robot.launch.py \
  z:=-0.5 namespace:=bluerov2 world_name:=dave_ocean_waves \
  paused:=false use_ardusub:=false use_teleop:=false

# Launch controller and bridge
ros2 launch bluerov2_path_control path_controller.launch.py \
  model_name:=bluerov2 use_bridge:=true

# Command a circle mission
ros2 service call /path_controller/follow_circle \
  bluerov2_path_interfaces/srv/FollowCircle \
  "{center_x: 0.0, center_y: 0.0, z: -0.5, radius: 1.0, period: 90.0, \
    turns: 1.0, clockwise: false, yaw_mode: 'tangent', yaw: 0.0, hold_at_end: true}"
Safety note: This package directly commands thruster force topics. It is intended for simulation and research. Test carefully in DAVE/Gazebo before using any logic on hardware.
