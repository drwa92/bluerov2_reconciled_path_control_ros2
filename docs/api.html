Mission service API

Before using these services: DAVE BlueROV2 must be running in direct-control mode and the controller launch must be active. See Quickstart.

Services

ServiceTypePurpose
/path_controller/go_toGoToMove to one pose and optionally hold.
/path_controller/follow_waypointsFollowWaypointsFollow a list of geometry_msgs/Pose waypoints.
/path_controller/follow_circleFollowCircleTrack a circle with fixed or tangent yaw.
/path_controller/follow_spiralFollowSpiralTrack an expanding or shrinking spiral.
/path_controller/follow_trajectoryFollowTrajectoryGeneric trajectory entry point for square, circle, spiral, and line paths.
/path_controller/stopstd_srvs/TriggerStop current mission and hold current pose.
/path_controller/emergency_stopstd_srvs/SetBoolZero thrusters and disable/enable control.
/path_controller/enable_reconciliationstd_srvs/SetBoolEnable or disable the optional virtual-wrench reconciliation module.
/path_controller/reset_reconciliationstd_srvs/TriggerReset the optional reconciliation estimate.

Go-to example

ros2 service call /path_controller/go_to bluerov2_path_interfaces/srv/GoTo \
"{x: 1.0, y: 0.0, z: -0.5, yaw: 0.0, speed: 0.15, hold_at_goal: true}"

Circle example

ros2 service call /path_controller/follow_circle bluerov2_path_interfaces/srv/FollowCircle \
"{center_x: 0.0, center_y: 0.0, z: -0.5, radius: 1.0, period: 90.0, \
  turns: 1.0, clockwise: false, yaw_mode: 'tangent', yaw: 0.0, hold_at_end: true}"

Waypoint example

ros2 service call /path_controller/follow_waypoints bluerov2_path_interfaces/srv/FollowWaypoints \
"{waypoints: [
  {position: {x: 1.0, y: 0.0, z: -0.5}, orientation: {x: 0, y: 0, z: 0, w: 1}},
  {position: {x: 1.0, y: 1.0, z: -0.5}, orientation: {x: 0, y: 0, z: 0, w: 1}}
], speed: 0.12, loop: false, hold_at_end: true}"

Emergency stop

ros2 service call /path_controller/emergency_stop std_srvs/srv/SetBool "{data: true}"
ros2 service call /path_controller/emergency_stop std_srvs/srv/SetBool "{data: false}"
